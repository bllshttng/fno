# Known command surface held by the CI ratchet.
# Every invocable leaf command, one per line, sorted: the fno-py registry (visible
# AND hidden, recursed to leaves) plus the Rust front's mux + version surface.
# Remove or add a line only in the same PR that removes or adds the command.
#
# ALLOCATE THE ACTION FIRST. A new action must have a row in
# scripts/ci/command-collapse-map.tsv before this file can regenerate, or the lint
# refuses with `collapsed action inventory drifted ... code-only=[...]`. Copy a
# neighbouring row: tier T1 keeps the pre-collapse typing, and the refs column
# comes from the sweep in scripts/diagnostics/command-callers.py, not from a guess.
# The map's contract test pins the inventory count, so that number moves in the
# same PR. Two separate branches hit this within one hour on 2026-08-13, which
# is why it is written here rather than learned twice.
#
# To regenerate after an intentional change:
#   cargo build --manifest-path crates/fno/Cargo.toml --bin fno
#   crates/fno/target/debug/fno doctor lint command-ratchet --update
# then commit this file in that PR. Run the checkout's own binary: the update
# logic lives in the same build CI gates, and a stale installed `fno` can
# regenerate from a differently shaped inventory.
# A deliberate addition carries a PR-body line:
#   command-exception: <rationale>
# (an explicit rationale keeps the exception reviewable).
# Two PRs that each add a command both edit this file; the merge conflict is the
# intended review moment, not tooling noise.
#
# A leaf carrying hidden options lists them inline as `!--flag` tokens
# (e.g. `mail send !--provider`); leaves with none stay single-token. Hidden options
# and deprecated aliases are the ungated axis this ratchet guards, so a new
# hidden option on an existing command carries its own PR-body line:
#   flag-exception: <rationale>
# (same shape as `command-exception:`; removals are free and need no line).
#
# Scope: the hidden-option coverage is fno-py only. The Rust front's COMMANDS are
#
# The fno-agents rows are enumerated live from the binary's own dispatch
# source and defended in both directions (agents_surface): a verb cannot be
# added or deleted silently. A dispatched verb the unknown-command refusal
# does not name is operator-invisible; its deliberate invisibility is
# recorded in scripts/ci/agents-hidden-verbs.tsv. The hidden verbs retire
# into nested groups per the fno-agents debt row in menu-caps-debt.tsv; a
# fold PR regenerates this file in the same change.

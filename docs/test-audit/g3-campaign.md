## Method

Round two read the cut at two scales. Rule 4 across the integration binaries. The loop_check, finalize_e2e, daemon_e2e and lead_loop boundaries pin their surfaces' contracts, so unit rows beneath them fold onto the boundary. The loopcheck nudge bytes, the decide parser pins and the codex-P1 unpinned keeper were body-checked and stayed. Rule 2 and rule 3 inside every family: tables cap at three rows per contract. One refusal case per fail-closed guard. The happy path and one edge. Deletion candidates were judged from test names first, then the rule-4 calls were verified against bodies. The bodies overturned three dup calls (the nudge byte rows, the parser incident pin, the unpinned attestation), which stayed.

The cut stops short because the scope's floor is real. The remaining rows are the scope's named contracts. They are incident pins (x2219 coverage-lane, the heartbeat x_d3ad, the codex-P1 unpinned attestation). They are fail-closed guards with their one refusal. They are golden byte tables, port-parity rows, and liveness-truth safety chains. Deleting them trades named contracts for the count, which rule 6 forbids. The rows name the rule that held each kept family: rule 3 held the refusal families. Rule 2 held the tables. The incident and parity rows hold themselves.

Under the standing freeze on local test runs, no cargo check or test ran locally. The fleet build door also refused a local check at this saturation (exit 86: commit, push, CI runs it). A mechanical dead-helper sweep ran instead: a helper whose name had no caller left got flagged for removal before push. CI's deny-warnings check is the authority. The preservation spot-check is waived for the same reason, as the README requires. One naming disclosure: the unchanged rows' failure clauses derive from each test's own contract name at name level, not from independent fault injection. The tests in this scope are contract sentences by convention. The cut calls were the body-verified judgments.

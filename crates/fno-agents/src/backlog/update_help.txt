Usage: fno backlog update <id> [<field><op><value>]... [OPTIONS]

Field operators (the argument carries the operator):
  field=value    set the field ('null' clears)
  field+=value   add to a list, or append a paragraph to text
  field-=value   remove from a list

  Fields (the kind fixes which operators a field takes):
    text     details, dispatch_brief, completion_note
             = sets ('null' clears), += appends a paragraph
             details= refuses a replace that would drop more than
             half of the stored details; --force replaces anyway.
    list     tags, blocked_by, related
             = replaces, += adds, -= removes
    records  additional_prs
             += adds one entry, -= removes it
    scalar   title, domain, size, model, type, batch, orphan_ok,
             priority, project, cwd, difficulty, dispatch_command,
             locked_by, plan_path, parent, caused_by, pr_number,
             pr_url, collisions_acknowledged, source_node_id
             (= only; 'null' clears)
    integer  fixes_pr  (= only; 0 clears)
    flag     public, reverted, has_brief  (= true|false)
  Modifiers that write no field stay flags: --force, --blocks-everything,
  --repo, --add-pr-url, --add-pr-note.
  A list value is one id or a comma list. Appending text the field
  already ends with changes nothing.

Lifecycle (never mixed with field writes in one call):
  --status <word>        move to idea|design|ready|deferred; a refusal
                         names the missing fact and the command that supplies it
  --leave <state>        leave deferred or superseded
  --set <field>=<value>  set a stored field through the patch door (repeatable)

Options:
  --details-file PATH             Read details from a file ('-' = stdin).
  --blocks-everything             Acknowledge that p0 blocks all downstream
                                  work.
  --to NEW-ID                     Rename the node id in place; the old id
                                  keeps resolving as an alias. Refuses a
                                  taken id, a live claim on the node, and
                                  mixing with field writes.
  --repo TEXT                     owner/name of the repo the PR lives in, when
                                  that differs from the cwd checkout; naming
                                  it makes the stamp an assertion.
  --add-pr-url TEXT               URL for the additional_prs+= entry (optional).
  --add-pr-note TEXT              One-line note for the additional_prs+= entry
                                  (optional).
  -F, --force                     Escape the one-plan-one-node refusal on
                                  plan_path=: bind this node to a plan
                                  another node already owns (a deliberate
                                  repoint). The other holder is still named on
                                  stderr. Also acknowledges a details= replace
                                  that drops more than half of the stored
                                  details.
  --help                          Show this message and exit.

Usage: fno-py backlog add [OPTIONS] TITLE

Arguments:
  TITLE  Feature title  [required]

Options:
  --domain TEXT           Domain profile  [default: code]
  -p, --priority TEXT     p0|p1|p2|p3  [default: p2]
  --blocks-everything     Acknowledge that p0 blocks all downstream work.
  --difficulty TEXT       Intrinsic work difficulty: low|medium|high.
  --blocked-by TEXT       Comma-separated ab-IDs
  --parent TEXT           Parent node ab-ID
  -t, --type TEXT         Node type: feature|epic|bug|roadmap  [default:
                          feature]
  --project TEXT          Project name. Defaults to the project whose `path:`
                          in settings.yaml matches the current working
                          directory.
  -c, --cwd TEXT          Project working directory. Defaults to the current
                          working directory.
  --roadmap-id TEXT       Roadmap group ID
  --vision-path TEXT      Source vision doc path
  -d, --details TEXT      Implementation guidance
  -e, --evidence TEXT     Record why the creator encountered this node.
                          Optional.
  --origin-evidence TEXT  Producing-event reference (mail id, event id, fu-id,
                          path). With --source-kind
                          from_observation/from_supervisor this is what makes
                          the node an agent discovery; without it the origin
                          stays unknown.
  --description TEXT      Alias for --details. Reads more naturally for an
                          idea-stage row. Mutually exclusive with --details.
  --size TEXT             Size estimate: S|M|L
  --batch TEXT            Execution batch group
  --source-node TEXT      Origin node this filing came out of (id, slug, or
                          bare hex). Overrides ambient capture. Refuses if it
                          does not resolve.
  --source-kind TEXT      organic|from_inbox|from_observation|from_supervisor|
                          operator_request. The `new` word also files from an
                          inbox: mark an operator ask with operator_request.
                          [default: organic]
  --source-project TEXT   Source project name (the new word's provenance).
  --source-inbox-msg TEXT Source inbox message ID (the new word's provenance).
  --source-inbox-thread TEXT
                          Source inbox thread file path (the new word's
                          provenance; `fno inbox drain` probes --help for it).
  --source-session-id TEXT Source session ID override (the new word).
  --unscoped              Create with project=null and cwd=null; skips the
                          auto-scope to the current git repo (the new word).
  --force-domain          Use --domain verbatim; skips the domain suggestion
                          (the new word).
  --help                  Show this message and exit.

  Paired verb: `fno backlog remove <id>` deletes it (hidden; run its own
  --help).

fno coordinates coding agents from a task to a reviewed pull request. It provides planning, worktrees, a backlog, agent messaging, and completion checks.

Use it when you run coding agents and want to track what they owe you. You need a Git repository and an authenticated coding harness.

## Get started

[Follow the quickstart](/quickstart): install fno and take one small change to a pull request.

The path is quickstart, completion concepts, then your first fleet. Reference pages stay available when you need an option or default.

## What you can do

- [Ship a change](/guides/ship-a-change): choose between one target and separate planning steps.
- [Run a fleet](/guides/run-a-fleet): give a worker a task and observe its progress.
- [Message agents](/guides/message-agents): send a follow-up and read its delivery state.
- [Manage a backlog](/guides/manage-backlog): record tasks and see their dependencies.
- [Review and ship](/guides/review-and-ship): check a PR before you merge it.

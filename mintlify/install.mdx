For a first installation and task, use the [quickstart](/quickstart). This page helps you verify an installation or choose a harness.

## What the installer changes

The installer provisions uv as needed, installs the fno CLI, and wires supported agent CLIs it detects.

It can add the tool directory to your shell profile. Restart your existing shell to pick up that path.

The installer supports these environment variables:

| Variable | Effect |
| --- | --- |
| `FNO_NO_WIRE` | Skip automatic plugin wiring when nonempty. |
| `FNO_NO_MODIFY_PATH` | Skip the shell-profile update when nonempty. |
| `FNO_INSTALL_DIR` | Choose the directory for installed tool commands. |
| `FNO_VERSION` | Install a specific published version. |

Skipping wiring leaves you with a CLI installation. It does not make workflow skills appear in your harness.

To wire a harness interactively, run this in a terminal:

```bash
fno do wizard
```

The wizard asks about setup and probes a harness before applying its choices. Review those choices before accepting them.

Inside Claude Code, type `/fno:` and look for `target` in autocomplete. In Codex, look for `fno:target` in its skill picker.

## Check your installation

In a new terminal, run:

```bash
fno --version
```

Success prints a version. If the shell says `command not found`, read the installer's tool-directory message and check your PATH.

Start a new coding-harness session. Confirm that `fno:target` appears among its skills before you try a workflow prompt.

The CLI also exposes its terminal command menu:

```bash
fno --help
```

Help lists CLI commands. Workflow skills such as `target` run inside a harness and have a different syntax.

## Project and account prerequisites

Use a Git repository with a remote you can push to. PR creation needs authenticated GitHub CLI access.

Authenticate the coding harness separately. A GitHub login does not provide model-provider access.

Installation does not create an account with either service. Confirm access before starting a target that can incur model costs.
